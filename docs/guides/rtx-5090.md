# RTX 5090

tqLLM runs on the RTX 5090 (32 GB, Blackwell, `sm_120`) with the same commands as on an RTX 3090 or 4090. Nothing is
5090-specific to set: the engine sizes itself from the card and the machine.

## Measured on one RTX 5090

RunPod RTX 5090 32 GB, PCIe 4.0 x16, AMD EPYC 7543 host, 117 GB container memory limit. One request at a time,
temperature 0, thinking off, second (warm) pass on the same server. Decode tokens per second; output byte-identical run
to run.

## What the engine picks by itself

- **Expert cache size**: `slots=auto` in the Flash-Next manifest fills the free VRAM after the dense weights, KV room
  and decode buffers (about 231 of 512 experts per layer on a 32 GB card at 128K context).
- **System RAM**: the routed experts are pinned in system RAM when they fit in 60 % of the machine's memory, else they
  are read from the GGUF on demand. Memory is the machine's RAM capped by the container limit (`memory.max` of its
  cgroup), so a Docker or cloud container with less memory than its host is sized correctly. Flash-Next IQ3_S needs
  about 85 GB of RAM for the pinned path (51 GB experts + 29 GB per-layer embedding).
- **CUDA graphs**: the per-layer decode graphs run on unified-memory GPUs (DGX Spark / GB10) only. On PCIe cards the
  engine launches the kernels directly: re-capturing the graphs every step cost more host time than it saved on a
  5090 with a server CPU (chat 128 -> 154 tok/s), and made no difference on a 3090 with a desktop CPU.

## Notes

- Long prompts: decode slows above 64K because the attention state takes VRAM from the expert cache. Prefill borrows
  expert banks for its buffers and gives them back after the prompt.
- A host CPU matters on this card: the GPU finishes a decode step quickly, so per-step host work (routing decisions,
  kernel launches) is a larger share than on a 3090. A desktop CPU with high single-core clocks helps.
- Switches that exist but are not needed on a 5090: see [FLAGS.md](../FLAGS.md). None of them were faster on this card
  (draft threshold, prefetch depth, CPU expert pool, expert tail skip, host KV).
